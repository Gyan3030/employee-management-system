# Employee Management System

A beginner-friendly DevOps project built using Linux,
Docker, PostgreSQL, and Bash scripting.

## Technologies Used

- Ubuntu Linux
- Docker
- PostgreSQL 16
- Docker Compose
- Bash
- Git

## Features

- PostgreSQL running inside a Docker container
- Employee database and SQL operations
- Persistent storage using Docker volumes
- Database backup using pg_dump
- Database restore testing
- Automated backups using Bash and cron

## Database Details

Database: employee_db

Table: employees
